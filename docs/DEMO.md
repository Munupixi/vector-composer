# Короткая демонстрация: 2–3 минуты

Запустить проект по README. Для сценария с нуля использовать новый профиль
браузера либо «Новая композиция». Библиотека при очистке холста сохраняется.

1. Открыть «Бумажный вихрь», выбрать персонажа кликом по рисунку или списку.
   Нажать «Сохранить в библиотеку», затем карточку персонажа.
2. Через «Все 20» показать каталог и фильтр подготовленных иллюстраций.
   Открыть «Вместе на пробежке», выделить собаку, сохранить и добавить на холст.
3. Открыть «Тихий вечер», выделить стопку книг, сохранить и добавить.
   На холсте теперь виден счётчик «Источников: 3».
4. Разнести объекты мышью. В правой панели изменить масштаб и угол.
   Выделить объект через список слоёв, продублировать и сдвинуть копию.
   Показать изменение порядка слоёв и удаление копии.
5. Переименовать композицию, обновить страницу и показать восстановление.
6. Нажать «Скачать SVG», открыть скачанный файл отдельно. В файле остаются
   векторные пути и отдельные группы объектов, без рамки выделения.
7. При необходимости открыть «Посмотреть примеры»: три композиции включены
   в проект и тоже редактируются по объектам.

## Что сказать об устройстве

«Я использую 20 готовых SVG одного стиля. Для трёх вручную подготовлены
логические группы — это разрешено заданием. При извлечении я сохраняю пути
и родительские группы с цветами и transform. Компонент переиспользуется,
а его экземпляры имеют независимые преобразования. Экспорт строится из
модели сцены и остаётся SVG. AI использовался для разработки приложения,
новые иллюстрации сервис не генерирует».

## Что передать проверяющему

- Ссылку на репозиторий и README с запуском.
- Короткую демонстрацию по этому сценарию или запись экрана.
- Три SVG из `public/examples`.
- Архитектуру и описание использованного AI из README.

Пока репозиторий приватный, проверяющему потребуется доступ. Публичная
публикация приложения не нужна для локального варианта сдачи.
