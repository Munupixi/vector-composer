# Демонстрация: около 2–3 минут

1. Выбрать «Время учиться» и нажать «Собрать композицию». При замене старой сцены подтвердить действие. Пояснение: подбор готовых объектов по теме и автоматическая расстановка.
2. Переключить S/L: показать разную детализацию исходников.
3. Выбрать квадратный формат и мятную схему.
4. Выбрать объект в слоях, изменить масштаб/позицию, роль на фоновую и обратно.
5. В режиме «По названиям компонентов» указать «книга, лампа, наушники» и собрать новую сцену. По желанию отключить фон.
6. Показать загрузку своей JSON-палитры. Пример скачивается из блока «Формат файла палитры».
7. Скачать SVG и открыть отдельно: векторный результат с отдельными группами.
8. По желанию показать три новых примера разных форматов.

Для короткой записи достаточно шагов 1–5 и 7. Разбирать весь код не нужно.
Обозначить ограничение: подбор использует локальный словарь тем и синонимов, не универсальную языковую модель.

## О решениях для обсуждения

«Продолжил редактор на React/TypeScript. Подключил векторы заказчика, сохранил настоящие S/L и роли. Запрос выбирает ID объектов, раскладка размещает их с равномерным масштабом. Подбор в MVP детерминированный, по словарю; его можно заменить отдельным сервисом, оставив библиотеку и редактор».

«Сцена хранится отдельно от SVG: экземпляры ссылаются на компоненты и содержат свои преобразования. Цвета меняются по слотам одним алгоритмом для холста и экспорта. Сохраняются ссылки и настройки; экспорт создаётся заново с уникальными ID».
