# Архитектура

## Поток данных

Запрос → ID готовых объектов → варианты S/L и роли → компоненты → раскладка → сцена → SVG.

React хранит модель сцены; нативный SVG отображает её. Backend для локального однопользовательского MVP не требуется.

## Библиотека

src/figmaCatalog.ts описывает десять объектов и словарь названий/тем.
У каждого четыре исходника: S/L × главный/фоновый.
Оригинальные экспорты — public/assets/figma-originals, варианты — public/assets/figma.
scripts/prepare-figma.py копирует группы из экспортов, не меняя контуры, атрибуты путей и внутренние преобразования.
Границы bounds.json измерены браузером через getBBox.
Прежняя библиотека Open Doodles остаётся в originals/prepared: три размеченных исходника, девять извлекаемых объектов.

## Подбор и раскладка

src/generation.ts нормализует русский запрос и ранжирует объекты: название/синоним весит больше темы.
Для метафоры выбираются до трёх объектов, для названий — все распознанные объекты библиотеки (до десяти).
Неизвестная тема не заменяется случайным результатом.
Это словарь, а не LLM: отрицания, сложные отношения и произвольные метафоры не интерпретируются.
Сетка с отступами подстраивается под формат; равномерный масштаб сохраняет пропорции.
Фон помещается первым в сцене. Повторная сборка переставляет объекты и меняет небольшие смещения.

## Извлечение и экземпляры

src/svg.ts сохраняет выбранную группу, её потомков, нужные родительские преобразования и defs. Браузер измеряет getBBox.
XMLSerializer сохраняет корректный SVG XML, включая неразрывные пробелы в исходных ID. HTML-сериализация могла бы породить недопустимую XML-сущность.

Компонент содержит разметку, размеры и ссылку на исходник.
Экземпляр хранит componentId, x/y, равномерный scale, rotation и роль.
Копии независимы. Порядок массива задаёт слои.
Pointer Events и обратная getScreenCTM переводят координаты мыши в координаты текущего холста; форматы определены в src/composition.ts.

При смене S/L и роли подставляется другой исходный SVG, сохраняются ширина и вертикальный центр экземпляра.
При смене формата композиция равномерно вписывается и центрируется.
При недопустимом масштабе операция отменяется с сообщением.

## Цвета

src/palettes.ts задаёт три схемы и порядок исходных слотов.
src/paint.ts меняет только цвета fill/stroke/stop-color, включая style.
Главные объекты используют objectColors, фоновые — backgroundColors.
Один алгоритм применяется на холсте и при экспорте, геометрия не меняется.
Палитра проверяется как данные: HEX-цвета, ограниченные массивы и имя, без URL/CSS/исполняемой разметки.

## Сохранение и экспорт

localStorage хранит версионированные ссылки на компоненты, экземпляры и настройки: формат, палитру, детализацию. Старые сохранения без новых полей поддерживаются.
SVG-разметка восстанавливается из доверенных файлов. Запись отложена на 300 мс, выполняется также при скрытии/закрытии страницы.

src/export.ts создаёт SVG из модели сцены с нужными width/height/viewBox и фоном палитры.
Каждый экземпляр — отдельная группа. ID и внутренние ссылки получают уникальные префиксы.
Рамки выделения и интерфейс в экспорт не входят.
