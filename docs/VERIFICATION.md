# Проверки — 19 октября 2026

Среда: Windows, Node.js 24.19.0, pnpm 11.25.0. Браузерные сценарии проверены
во встроенном браузере и Microsoft Edge.

## Сборка и автоматические проверки

В отдельную временную папку скопированы исходники без node_modules и dist.
Из этой чистой копии выполнены:

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

Все команды завершились успешно. Vitest: **5 файлов, 24 теста**.
Проверены сохранность исходных путей, извлечение групп, цвета и родительские
преобразования, ID и ссылки, копии, масштаб вокруг центра, порядок слоёв,
валидация сохранённых ссылок и SVG-экспорт.

Отдельный тест проверяет, что пути трёх поставляемых композиций принадлежат
подготовленным исходникам: новые графические контуры не добавляются.

## Границы проверки

Экспорт проверен структурно и в браузере. Открытие в Adobe Illustrator или
Inkscape отдельно не проверялось. Все действия с пользователями, серверная
синхронизация и универсальный импорт SVG находятся вне границ MVP.

Некорректные сохранённые данные покрыты тестами валидации. Принудительное
отключение localStorage и переполнение квоты вручную не проверялись.
