# Сочетай — конструктор векторных композиций

Браузерный редактор на React + TypeScript: подбирает готовые SVG-объекты по заголовку или названиям, автоматически расставляет их и позволяет доработать композицию вручную. Новые графические контуры не генерируются.

## Запуск

Нужны Node.js 22.12+ и pnpm 11.25.0. Сервер приложений и база данных не нужны.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173.

```powershell
pnpm test
pnpm build
pnpm preview
```

preview запускает готовую сборку, обычно на http://127.0.0.1:4173. После установки зависимостей приложение работает без внешних API.

## Возможности обновлённого задания

- Библиотека из предоставленного макета: 10 объектов, настоящие варианты S/L и главный/фоновый — всего 40 SVG. S отличается детализацией, а не только масштабом.
- Автосборка по заголовку/метафоре: «Время учиться», «Финансовая подушка», «Работа в команде».
- Подбор по названиям: книга, телефон, пазлы, монета, наушники, лампа, папка, ручка, кошелёк, цветы. Можно собрать все десять главных объектов за один запрос.
- Горизонтальный холст 1200 × 800, квадрат 1080 × 1080, вертикальный 800 × 1200.
- Три схемы из макета: лавандовая, персиковая, мятная. Своя палитра загружается JSON-файлом и автоматически применяется к объектам. Цвета фона выбираются из отдельного набора палитры.
- Необязательный фоновый объект; роль можно изменить в свойствах. Подставляется соответствующий оригинальный вариант.
- Ручное перемещение, равномерный масштаб, поворот, копирование, удаление, порядок слоёв и повторное использование компонентов.
- Автосохранение сцены, детализации, формата и палитры в этом браузере.
- Экспорт самостоятельного SVG с отдельными группами, исходными контурами и уникальными ID.
- Три новых редактируемых примера и три прежних примера Open Doodles.

Прежний каталог из 20 Open Doodles сохранён: 9 извлекаемых объектов в трёх подготовленных иллюстрациях, остальные — для просмотра. Он доступен через переключатель в каталоге. Переключение S/L относится к библиотеке Figma.

Клавиши: Delete/Backspace — удалить, Ctrl+D/Cmd+D — копия, стрелки — сдвиг, Shift+стрелки — на 10. В полях ввода команды не перехватываются.

## Быстрая проверка

1. Нажмите «Время учиться», затем «Собрать композицию».
2. Переключите S/L, формат и цветовую схему.
3. Выберите объект в слоях, измените роль или масштаб.
4. Скачайте SVG; откройте файл отдельно.
5. Перезагрузите страницу — сцена и настройки восстановятся.

## Палитра

[Пример JSON](public/palettes/example.json). До 32 КБ. Поля: name, background, backgroundColors, objectColors. Цвета — #RRGGBB; фон должен входить в backgroundColors. Порядок objectColors: три фоновых оттенка, три акцента, контур, белый. При другой длине списка соответствие цветов повторяется по кругу. Геометрия и пропорции при перекрашивании сохраняются.

## Устройство и ограничения

React + TypeScript + Vite, нативный SVG. Дополнительных зависимостей для редактора и распознавания текста нет.

Подбор использует локальный словарь названий, тем и синонимов, затем геометрическую раскладку. Это ограниченный MVP, а не языковая модель: неизвестная тема выдаёт сообщение. В смешанном запросе используются распознанные объекты; неизвестные слова пропускаются. Повторная сборка меняет порядок и небольшие смещения, но не создаёт новые рисунки.

Палитра импортируется только как JSON, без извлечения цветов из изображений. SVG загружаются только из доверенной библиотеки; произвольный импорт, undo/redo, совместная работа и серверное хранение не реализованы. Сохраняется одна сцена на браузер и адрес сайта. Основной сценарий рассчитан на настольный браузер.
