# Источники иллюстраций

- Автор: Pablo Stanley.
- Набор: Open Doodles — https://www.opendoodles.com/
- Условия автора: https://www.opendoodles.com/about — CC0.
- Дата загрузки: 19 октября 2026.
- Оригинал `clumsy.svg`: https://opendoodles.s3-us-west-1.amazonaws.com/clumsy.svg
- Подготовка: пути распределены по трём логическим компонентам, повторяющиеся
  ID заменены уникальными. Геометрия, цвета и преобразования оригинала сохранены.

Все 20 исходников включены локально; обращения к внешним сайтам при работе
редактора не нужны. Их имена перечислены в `scripts/download-assets.py`,
каждый оригинал доступен по адресу `https://opendoodles.s3-us-west-1.amazonaws.com/{имя}.svg`.

Дополнительно подготовлены `dog-jump.svg` (собака, персонаж, линии движения)
и `sitting-reading.svg` (читатель, стопка книг, отдельная книга). В dog-jump независимый контур языка собаки
выделен из общего цветного пути: команды рисования сохранены без изменений.
